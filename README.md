# BaiA2
chủ đề 1: Quản lý danh sách Sinh viên Xây dựng lớp quản lý đối tượng Sinh viên với các thuộc tính: mã sinh viên, họ tên, lớp, điểm học phần 1, điểm học phần 2, điểm học phần 3, điểm trung bình và các phương thức cần thiết. Sau đó thực hiện quản lý danh sách n (0 < n < 200) sinh viên với các thao tác: 
Nhập danh sách sinh viên từ bàn phím, in danh sách ra màn hình; 
Sắp xếp danh sách theo thứ tự điểm trung bình giảm dần; 
Tìm kiếm sinh viên theo mã sinh viên; 
Bổ sung hoặc xóa 1 sinh viên ở một vị trí cho trước trong danh sách. 

Khởi tạo 2 lớp:
- Lớp sinh viên:
  + Thêm sinh viên
  + In thông tin sinh viên
  + Điểm trung bình sinh viên
- Lớp quản lý sinh viên:
  + Thêm thông tin n sinh viên
  + In thông tin n sinh viên
  + Tìm kiếm sinh viên
  + Thêm sinh viên
  + Xóa sinh viên
